# 🌴 HH GOA 2026 – Frame & Builder ID Card Generator

Create your own official **Hacker House Goa 2026** Builder Badge or Profile Picture Frame in just a few clicks. Upload your photo, personalize your details, generate a beautiful branded graphic, and share it directly on social media.

🔗 **Live Demo:** https://hhgoa-frame-studio.vercel.app/

---

## 📖 Overview

The **HH GOA 2026 Frame Studio** is a web application built for the Hacker House Goa 2026 challenge. It enables builders to instantly create personalized, event-branded graphics that are ready to download and share on X (Twitter) and LinkedIn.

The application is designed with a **mobile-first**, **fast**, and **no-login** experience, allowing users to complete the entire process within seconds.

---

## ✨ Features

### 🎨 Two Builder Formats

#### **Format A – Profile Picture Frame**
- Official HH GOA 2026 branded profile frame
- Smart photo positioning
- Automatic image scaling
- High-quality PNG export
- Social media optimized

#### **Format B – Builder ID Card**
- Builder photo
- Name
- Role / Stack
- AI Generated Builder Title
- AI Superpower
- QR Code
- Official HH GOA 2026 branding
- High-resolution downloadable badge

#### **🧊 3D Interactive Card Render & 6s Reel Exporter**
- Real-time 360° HD PVC Card & Woven HHGOA Lanyard render
- Bright dual-sided front & back lighting
- 6-second 9:16 vertical 360° spin video export (`🎬 EXPORT 3D`) ready for Reels & Stories

#### **📱 Progressive Web App (PWA) & 100% Offline Support**
- Installable on Mobile (iOS / Android) & Desktop as a native standalone app
- Service Worker (`sw.js`) Stale-While-Revalidate caching strategy
- Generate, customize, and export 2D & 3D badges off-grid with zero Wi-Fi connection
- Live Offline Mode alert (`⚡ OFFLINE MODE ACTIVE`) & floating install banner

# 🚀 Getting Started

## Prerequisites

- Node.js 18+
- npm / yarn / pnpm

---

## Clone Repository

```bash
git clone https://github.com/your-username/hh-goa-frame-studio.git

cd hh-goa-frame-studio
```

---

## Install Dependencies

```bash
npm install
```

or

```bash
yarn
```

---

## Start Development Server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

# 🖥 Usage

1. Upload your photo
2. Choose **Profile Frame** or **Builder ID Card**
3. Enter your details
4. Select a theme
5. Position your image
6. Generate your badge
7. Download the PNG
8. Share directly to X or LinkedIn
